### 👨‍💻 About Me

I'm a final-year Computer Science student at FUNAAB, currently building **n8n automation workflows and RAG-based AI systems**. I design and ship automation pipelines — webhook-triggered AI agents, document-grounded chatbots, and ops-facing workflows — and pair that with frontend/UI-UX skills from my SIWES track.

I care about building automation that's **actually production-aware**: rate limits, OAuth token lifecycles, structured outputs, and knowing which workflows are safe to automate versus which ones need compliance sign-off. That last part matters more in fintech than anywhere else.

---

### 🤖 Automation & AI Engineering

**What I actually build:**
- RAG-pattern chatbots: document ingestion → vector store → AI Agent → webhook response
- Multi-step business workflows: Form/Webhook Trigger → AI Agent → processing → notification/logging
- Self-hosted n8n infrastructure: Docker Compose, Postgres, Redis, multi-container production setups

**Engineering details I've actually debugged**, not just used:
- Migrated a Chat Trigger architecture to Webhook-based to enable post-processing of AI Agent responses
- Fixed broken tool-calling behavior by rewriting vector store tool descriptions to be directive rather than passive
- Iterated on system prompts to force structured, consistent output formatting from LLM responses
- Solved Google OAuth2 token expiry by moving an app from Testing to Production mode
- Worked across multiple LLM providers (Groq, Mistral, Gemini) based on rate-limit and integration constraints, not just whichever was easiest

**Where I draw the line:** I've also turned down automating workflows that touch regulated/compliance-adjacent operations without proper sign-off — knowing what *not* to automate is part of the job in a company.
